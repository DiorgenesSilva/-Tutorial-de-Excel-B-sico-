# TUTORIAL BASICO DE EXCEL
 A base de dados disponibilizada para o início do tutorial simula a operação real de uma grande **Distribuidora Logística e Gerenciamento de Cadeia de Suprimentos**. Trata-se de uma base integrada composta por 5 grandes frentes operacionais, para o aprendizado de conceitos como navegação, filtros, formatação e as primeiras fórmulas matemáticas.
